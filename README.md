# Instructions
There are different files and in each file we test our different Deep Learning with/without feature engineeing and also we test the classical approaches with `u_in`, `u_out`, `R_20`, `R_5`, `R_50`, `C_10`, `C_20`, `C_50` features:

* GRU_feature_engineering.ipynb
* GRU_without_feature_engineering.ipynb
* LSTM_feature_engineering.ipynb
* LSTM_without_feature_engineering.ipynb
* RNN_Feature_Engineering.ipynb
* RNN_without_feature_engineering.ipynb
* classical approaches.ipynb
